## 2. The idea of the right method (in simple words)
In the real plant the DCS never writes the PV. The **plant** answers: the valve moves, the pressure changes, the transmitter sends a new number to the DCS input card. The simulator has no plant, so today every field number is a slider that the user must move by hand, and where the assistant added a "process model" it pushes the number INTO THE MIDDLE of the logic (as a force), skipping the transmitter selection, the averaging, the deviation alarms of the sheet. That is why it looks forced and why the logic behind it is not really exercised.

Right method = copy the real boundary:
1. **Logic of the sheets stays as drawn** (the engine we already tested: 2 973 blocks).
2. **The I/O boundary is the only place where the plant touches the logic**: the plant model writes the INPUTS (AI, DI) exactly where the field would, never the middle of the logic and never a force.
3. **A plant layer (new)** reads the OUTPUTS of the logic (AO, DO, PID MV, commands) and computes the field signals:
   - Loop: MV -> PV with gain, time constant, dead time (what we have, but writing the transmitter inputs: all the redundant transmitters of one measurement get the same value, the logic then selects / averages / alarms as in the plant).
   - Actuator: AO command -> position feedback (stroke time); DO command -> DI feedback (running, open, closed) after a delay.
   - Disturbances: a short named list (load, ambient, fuel quality) that the user MAY edit.
4. **Who may be edited by the user**: SV, manual values, switches, mode inputs (.MAN / .LOC / .REM), COS, and the named disturbances. PV and feedbacks: read only, always (the 6 PID without a field PV and the 107 independent measurements become either disturbances or modelled feedbacks, see below).
5. **A plant table** (editable in the app, saved with the project): one row per loop / actuator / feedback: what drives it, gain, T, dead time. Pre-filled by rules from the drawings and tag names; the user (who knows the plant) corrects the rows. Real numbers need a step test on the plant, the table is where they will go.
