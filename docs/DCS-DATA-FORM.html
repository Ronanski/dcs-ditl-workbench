How to use. Every row gives the TAG, the DESCRIPTION and the ADDRESSES (function block MDL address as written on the drawing, and the field signal address with its IO-list tag) so you can find it in the DCS. The grey boxes are what the simulator uses now (ASSUMED, not from the DCS). Write the real DCS value in the white boxes. A "-" means not used / not present. Order: G single questions and H drum level tables (page 1) · A alarm limits (104) · B PID tuning (68) · C ramp rates (8) · D pulse output (2) · E select circuits (26) · F totalizers (10).

Priority if you have little time: G1–G6 and section H first (a few minutes), then B (PID tuning), then A (alarms). C, D, E, F are short.

Signal address = the AI address read from the drawing (and the IO-list tag/description of that address). Where a PID has several field signals upstream (ratio, 3-element control) all are listed; the first one is the measurement of the loop tag. "no AI on this sheet" means the input is calculated or from an operator station / another sheet (the MDL address is then the way to find it).
