2. Ano ang ibig sabihin ng status

StatusIbig sabihin
PASS / NAAYOSTugma sa tamang inaasahan, may actual na test record. Ang "NAAYOS" ay ayos na ayon sa automated test ko; ikaw pa rin ang magko-confirm sa manual test.
FAILHindi tugma. May sira.
NEEDS REVIEWHindi ko masabi kung ano ang tama dahil kulang ang nakasulat sa drawing o sa data. Hindi ako humuhula. Sinasabi ko kung bakit at kung ano ang kailangan ko.
NOT TESTED / HINDI PA GINAGAWAWalang test o hindi pa nagagawa.

3. Paano ko inayos (maikli)

  1. Inaral ko muna ang bawat block: legend (ABC-000), pin, + / - , range, source ng input.
  2. Gumawa ako ng test na tumatakbo sa lahat ng sheet (hindi lang sa isang halimbawa), para ang ayos ay umabot sa lahat.
  3. Pagkatapos ng ayos, in-run ko ulit ang lahat ng lumang test para siguradong walang nasira. Hindi ginalaw ang DITL page (guard: IDENTICAL).
