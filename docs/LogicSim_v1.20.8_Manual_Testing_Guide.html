Logic Sim v1.20.8 - Manual Testing Guide

Para sa non-coder. Petsa: 2026-10-10. Gamitin ang HTML: https://github.com/Ronanski/dcs-ditl-workbench/releases/download/v1.20.8/logic-sim-v1.20.8.html sa Chrome.
Paano gamitin: Gawin ang bawat test ayon sa hakbang. Isulat ang nakita mo sa "Actual result mo" at lagyan ng PASS o FAIL. Kung hindi tugma, gawin ang nasa "Kapag hindi tugma". Lahat ay NOT TESTED hanggang magawa mo. Ang "Rehearsal result" ay ang nakita ko sa headless browser; hindi iyon ang test mo.
Mga salita: View = default, grey, walang simulation. Run = pindutin ang ▶ Run para tumakbo. Panel = ang kanang bahagi na may listahan ng inputs. Analog · ABC = button sa taas para sa analog sheets. Ang sheet ay pinipili sa listahan sa taas (hal. "ABC-002").

MT-02 - ABC-002

ItemDetalye
SheetABC-002
Block / tagDalawang O2 transmitter: AI0273 (SIG.AB B.0671) at AI0433 (SIG.AB B.0701)
Starting conditionRun, default na lahat OFF.
Mga hakbang
  1. Piliin ang sheet ABC-002.
  2. Sa Panel, hanapin ang grupong Bad Signal (SIG.AB) - simulation only, OFF by default.
  3. Tingnan na ang dalawang button ay nagsasabing Bad Signal: OFF.
  4. Pindutin ang button sa ilalim ng SIG.AB B.0671.
  5. Tingnan ang diagram sa ibabaw ng transmitter AI0273.
  6. Pindutin ulit ang button (ngayon ay FORCED BAD (ON)).
Inaasahang resultaHakbang 3: parehong OFF. Hakbang 4: nagiging FORCED BAD (ON); sa diagram may pulang FORCED BAD sa ibabaw ng transmitter. Hakbang 6: bumabalik sa Bad Signal: OFF at nawawala ang pulang marka.
Rehearsal result (ako, hindi mo test)Sa pagsubok: OFF sa simula; ON ay nagpakita ng 1 marka na "FORCED BAD"; OFF ay nagtanggal nito.
Actual result mo 
 
StatusNOT TESTED (gawing PASS o FAIL pagkatapos)
Kapag hindi tugmaKung walang pulang marka, o hindi bumalik: FAIL. Kunan ng screenshot ng diagram at panel.

MT-03 - ABC-002

ItemDetalye
SheetABC-002
Block / tagAverage select circuit, tag SI0048
Starting conditionPindutin ang ▶ Run. Lahat ng Bad Signal = OFF.
Mga hakbang
  1. Sa Panel, sa Analog inputs, ilagay sa AI0273 ang 4.30 at sa AI0433 ang 4.60 (ang range ay 0 hanggang 25 %).
  2. Basahin ang value sa tabi ng SI0048 sa diagram.
  3. I-ON ang Bad Signal ng B.0671 (AI0273). Basahin ulit ang SI0048.
  4. I-OFF ito. Basahin ang SI0048.
  5. I-ON ang Bad Signal ng B.0701 (AI0433). Basahin ang SI0048. I-OFF ito.
  6. Ilagay sa AI0273 ang 0 (zero, walang Bad Signal). Basahin ang SI0048.
Inaasahang resultaHakbang 2: 4.45. Hakbang 3: 4.60 (hindi na isinama ang bad). Hakbang 4: 4.45. Hakbang 5: 4.30. Hakbang 6: 2.30 (ang zero ay valid na reading, hindi bad: (0 + 4.60) / 2).
Rehearsal result (ako, hindi mo test)Nakuha ko: 4.45 / 4.6 / 4.45 / 4.3 / 2.3. (Kapag parehong bad, hawak ang huling magandang value 4.3: umiiral na logic, hindi nakasulat sa drawing.)
Actual result mo 
 
StatusNOT TESTED (gawing PASS o FAIL pagkatapos)
Kapag hindi tugmaKung iba ang value: FAIL. Isulat ang nabasa mo sa bawat hakbang at ipadala.

MT-04 - ABC-002

ItemDetalye
SheetABC-002
Block / tagConstant "32% MIN. AIR FLOW" (kahon na "A" sa tabi ng 32%)
Starting conditionView o Run. Wala pang binabago.
Mga hakbang
  1. Piliin ang sheet ABC-002.
  2. I-click ang maliit na kahon na may A sa tabi ng "32% MIN. AIR FLOW".
  3. Sa Panel, hanapin ang Minimum air flow setting (T/H) - editable. Basahin ang numero at ang ibang linya.
  4. Palitan ang numero ng 500 at pindutin ang Enter.
  5. Basahin ang linyang Signal to the high selector now.
  6. I-refresh ang page (F5), piliin ulit ang ABC-002 at i-click ulit ang kahon na A. Basahin ang setting.
  7. Pindutin ang Back to the drawing value (32 % = 400 T/H).
Inaasahang resultaHakbang 3: 400; "Original drawing constant: 32 %"; may dilaw na NEEDS REVIEW tungkol sa conversion. Hakbang 5: 40 % (500 x 0.08). Hakbang 6: nananatili ang 500 pagkatapos ng F5. Hakbang 7: bumabalik sa 400 at 32 %.
Rehearsal result (ako, hindi mo test)Default 400; 500 ay nagbigay ng 40 %; Back ay nagbalik sa 32 %; nanatili ang 500 pagkatapos ng reload.
Actual result mo 
 
StatusNOT TESTED (gawing PASS o FAIL pagkatapos)
Kapag hindi tugmaKung hindi nag-update o nawala ang 32 %: FAIL, screenshot ng panel.

MT-05 - ABC-001D at ABC-032

ItemDetalye
SheetABC-001D at ABC-032
Block / tagRATE FM403 (ABC-001D) at ramp "RAMP:1% / sec" (ABC-032)
Starting conditionView mode ay okay.
Mga hakbang
  1. Piliin ang ABC-001D.
  2. I-click ang kahon ng FM403 (may nakasulat na "2.7T / HR = 2.25% / HR").
  3. Sa Panel, tingnan ang Rate (signal units per sec).
  4. Piliin ang ABC-032.
  5. I-click ang kahong BUMPLESS na "RAMP:1% / sec" (sa pagitan ng SI0230 at SI0231).
  6. Tingnan ang Rate (signal units per sec).
Inaasahang resultaHakbang 3: 0.00075. Hakbang 6: 2 (1 % ng 0-200 T/H).
Rehearsal result (ako, hindi mo test)Nabasa ko: 0.00075 at 2.

Kapag hindi tugmaKung ibang numero ang nakita: FAIL. Isulat ang numero. Tandaan: ang drawing ay hindi nagsasabi ng range ng ramp; ang 200 T/H ay mula sa PID range at sa kumpirmasyon mo.
