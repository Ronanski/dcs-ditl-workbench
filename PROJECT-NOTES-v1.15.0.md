# Logic Sim - PROJECT NOTES (changelog, newest first)

**Logic Sim** is an offline simulator and viewer of a plant's DCS logic drawings: the DITL digital pages and 54 analog (ABC) control sheets. It reads the drawings (DXF), builds the logic and runs it: inputs, forces, switches, timers, PID loops, valves, with live colours on the wires. It runs as one html file in Chrome, as a portable Windows app and as an Android app.

Rules are NOT here any more: see DESIGN.md. Older entries (v1.8.1 and before): archive/notes/CHANGELOG-to-v1.8.1.md

## v1.14.0 (logic-sim-v1.14.0.html) - three modes: VIEW / RUN / PAUSE (Back + Next), auto-trace, thin solid wires
- USER design (replaces the v1.13 Trace button and the +1 scan / +1 s / +10 s buttons).
- **VIEW** (default when the app opens): every wire plain grey, nothing simulated, no inputs / force. Click a block or a wire = it is traced automatically (glow: white selected, blue driven by, magenta feeds; rest dimmed; list in the panel). Click an empty place = trace gone. No Trace button any more.
- **RUN**: the wires that should be live light up. Pressing Run from VIEW forces nothing by itself; forced / simulated values exist only after the user sets them and are removed only by Reset. Going back to VIEW hides them (and the state), RUN shows them again.
- **PAUSE**: same colours as RUN, frozen. Step 1 / 5 / 10 / 30 / 60 s with **Next ▶** (forward) and **◀ Back** (rollback). Back restores the whole simulation state (values, timers, valves, PID) from a history of snapshots kept while running / stepping (one per simulated second, up to ~10 min, fewer when many sheets are linked); if the nearest snapshot is earlier it replays forward to the exact time. Inputs changed after that moment are not replayed. Reset clears the history. History is per opened sheet (with its linked sheets).
- **Wires**: default is thin and solid for live digital AND analog (the double-line tube is still a choice in Legend & style); a saved older setting is migrated once (wv:2). Digital grey = 0; analog always coloured (carries a value, even 0); only VIEW is grey.
- TESTED here (Chromium): tools/test-modes.js (view default, grey, click = trace, blank = clear, Run leaves VIEW, no trace in RUN, Next +10 s, Back restores time and ALL net values, Back 5 s after two Next, Back 1 s after a free run, return to VIEW, Reset clears history) + the older tests (project, storage, numinput, pid, ln, anim, circles, ades) with VIEW switched off first. ## v1.11.0 (ditl-workbench-v1.11.0.html) - REAL PID (user: "can the gains wait? fix the PID now")
- Gains are NOT needed to get the controller structure right: they only decide how FAST the output moves, not WHAT it does (modes, direction, limits, tracking, which signals drive it). So the PID is built now with DEFAULT tuning (Kp 1, Ti 60 s, Td 0) that is EDITABLE per block in the block panel (saved in the project file); the real values live in the DCS database and can be typed in / imported later.
- Algorithm: input = the DEVIATION from the DEV block (SV - PV) as drawn; es = ±deviation / span x 100 (span = range of the transmitter that feeds the deviation, found by tracing upstream, else 100); u = Kp*(es + integral(es)/Ti + Td*des/dt), clamped to the output range (default 0..100), integral frozen / back-calculated at the limits (anti-windup); at dt = 0 (Pause) only the proportional part moves; when the T/AMT after the controller is on another input the controller TRACKS that output (bumpless), the existing tracking hook of the selector is used.
- BUG FOUND AND FIXED: the ACT:R / ACT:N text is above the box, the old reader looked at its corner, so ALL 68 controllers were read as one action. Now 38 are reverse (ACT:R: flow / level feed) and 30 normal = direct (ACT:N: steam pressure blow-off), consistent with the process and with the DCS Module Wiring "Act (N:Nr, R:Rv)".
- TEST tools/test-pid.js (ABC-017, first-order plant): reverse action + positive plant reaches SV (30) and follows an SV step; Pause does not move the integrator; anti-windup recovers (MV 100 -> 47 after the error reverses); manual value 37 -> PID tracks 37, back to auto 37.00 -> 37.02 (bumpless); direct + negative plant converges; ACT parsed 38 / 30.
